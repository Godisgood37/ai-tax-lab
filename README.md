# ai-tax-lab

A public learning lab where I build practical AI tools for Irish tax and accounting, as part of my 26-week AI Authority Programme: Tax & Accounting.

Everything I build during the programme lives in this repository, and `LOG.md` records what I did and learned each session.

## Focus areas

- Irish income tax (Form 11), CGT and CAT workflows
- Extracting and organising client information with AI
- Populating working papers from structured data
- Research tools over Irish legislation and Revenue guidance

## Important: no client data

This repository is public. It must never contain:

- Real client names, PPS numbers, addresses, or financial details
- API keys or passwords (use a local `.env` file, which is in `.gitignore`)

All examples and test data are fictional or anonymised.
